# Verse v1 plan

Goal: build the Verse v1 meeting assistant so that the speed targets in spec section 6 are met and measured.
Spec: `docs/specs/2026-10-14-verse-meeting-assistant-v1-design.md` (approved by Alex 2026-10-14); critique:
`docs/specs/2026-10-14-speed-critique.md`.
Approach: Phase 0 measures the four unknowns that can change the design (API latency, speech latency, Brave
audio capture, rate limits), with throwaway CLIs. Only after Alex accepts the numbers does Phase 1 build the app
(Swift + Python brain). The Phase 1 packages are fixed in scope and order now; their test cases and thresholds
are finalised from the Phase 0 results.

Global constraints (verbatim from the spec):
- Models: `claude-haiku-5-5` (S/F: effort low, thinking disabled) and `claude-sonnet-5-5` (D: effort medium,
  thinking `between_tools` unless measured otherwise). Prep runs on `claude-sonnet-5-5` at effort high.
- Paid only from the Max monthly API credit: an API key from "Personal API Org", read from the Keychain item
  `verse-anthropic` (account = `$USER`). Never print, log or write the key. No Claude.ai/Max OAuth.
- Python: official `anthropic` SDK ≥ 1.13 (pinned in `requirements.txt`) and `httpx[http2]`. No other LLM
  provider.
- No audio file is ever written. Measurements store numbers only (timings, RMS, transcripts of synthetic test
  audio).
- t = 0 is the acoustic end of the question; every timing is logged per stage.
- No GUI windows during tests (CLI only); kill every process you start, also on failure (memory
  `feedback-gui-test-windows`).
- macOS 26, Xcode 27, Swift 6. No git commits or pushes without the owner's OK.

Packages: Phase 0 = P0-A, P0-B, P0-C, which run in parallel (disjoint folders). Then a gate: Alex reviews
`bench/RESULTS.md`. Phase 1 = P1-1 … P1-6 (order below).

| `bank.jsonl` | One `{id:"b001", lang, question, paraphrases:{<lang>:[str]}, opener, points:[str,str,str], deep, sources:[{kind:"prep"\|"vault"\|"commit", ref, quote}]}` per line |

| `snippets.jsonl` | `{id:"s001", ref, text, bank_ids:[…]}` |
| `pack.md` | The frozen meeting pack (the cache prefix). Deterministic: the same inputs give byte-identical output |
| `review.md` | The human-readable bank, for Alex to read and correct before the call |

### Package P1-2: Brain runtime
Agent: worker-xhard · Owns: `brain/verse_brain/runtime/**`, `brain/tests/test_runtime*.py` · Do not touch:
`brain/verse_brain/prep/**` (P1-1), `app/**` · Starts after P1-1 is accepted.

pre-warm, Sonnet `between_tools`, Haiku `disabled`)
Decisions:
- Process: `python -u -m verse_brain.runtime`, speaking JSON lines on stdin/stdout and logging to stderr. Every
  stdout line is flushed.
- Routes (byte-identical settings tuples, including pre-warm and keep-alive):
  - S/F: `claude-haiku-5-5`, effort low, `thinking:{type:"disabled"}`, max_tokens 120.
  - D: `claude-sonnet-5-5`, effort medium, `thinking:{type:"between_tools"}`, max_tokens 600.
  - Fallbacks: `fallbacks:"default"` on D only (claude-api skill).
- Prompt layout per spec §5.8: system → `pack.md` (breakpoint 1) → finalized turns (breakpoint 2, moved forward at
  most every 4 turns) → the current text.
- **S:** up to 3 calls in flight per turn. Fire when the partial has ≥ 4 new words since the last fire, at least
  300 ms after it, and carries a question cue (supplied by Swift in `partial.cue`).
- **F:** at `turn` if no S call's input is within edit distance ≤ 3 tokens of the endpoint text.
- **D:** fires early when the partial is unchanged for 700 ms and has a cue or a bank hit; otherwise at `turn`.
  Skipped when the `bank_hit` score is ≥ 0.85 and Haiku agrees.
- **Transport:** one warm `DefaultAsyncHttpxClient(http2=True, keepalive_expiry=300)` per model, a
  `count_tokens` ping every 30 s, a hedged duplicate after 1.5 s without a first byte, and `max_retries=0` on
  S/F and 1 on D.
- A token bucket per model at 80 % of the headers' limits.
- Cache keep-alive (`max_tokens: 0`, non-streaming) after 240 s without a call.
Interfaces — Consumes: the session folder contract.
- **Swift → brain:**
  - `{"type":"start","session_dir":str,"lang":"en|it|tr"}`
  - `{"type":"partial","turn_id":str,"speaker":"remote|me","text":str,"cue":bool,"t_audio_end":float}`
  - `{"type":"turn","turn_id":str,"speaker":"remote|me","text":str,"addressee":"me|other|unknown","kind":"question|statement|fragment" (optional),"t_audio_end":float}`
  - `{"type":"bank_hit","turn_id":str,"bank_id":str,"score":float}`
  - `{"type":"control","action":"stop|summarize"}`
- **Brain → Swift:**
  - `{"type":"delta","id":str,"turn_id":str,"tier":"S|F|D","text":str,"line_done":bool}`
  - `{"type":"select","turn_id":str,"id":str}`
  - `{"type":"opener_status","turn_id":str,"ok":bool}`
  - `{"type":"bank_verdict","turn_id":str,"bank_id":str,"agree":bool}`
  - `{"type":"actions","items":[str]}`
  - `{"type":"status","state":"warming|ready|offline|rate_limited|credit_exhausted|refusal|error","message":str}`
  - `{"type":"metric","turn_id":str,"stage":str,"t":float}`
- Model output lines: `SAY: …`, `- …`, `BANK: <id>|none` (S/F), `KIND: question|statement` / `NONE` (statement probe), and
  `OPENER_OK` / `OPENER_WRONG` (first line of D). Fragments get no calls; statements get at most one short ack.
Test cases (with a fake streaming client unless marked live):

- `test_speculation_policy`: a scripted partial timeline → fires at the expected times, never more than 3 in

- `test_f_fallback`: no S call close to the endpoint text → exactly one F call at `turn`.

- `test_hedge`: a fake first call with no first byte for 2 s → a second call starts at 1.5 s, the first one to

- `test_opener_wrong`: D's first line `OPENER_WRONG` → an `opener_status ok=false` event is emitted before any D

- `test_addressee_other`: `addressee:"other"` → no S/F/D calls, and the event is forwarded for display only.
- `test_refusal_and_429`: fake refusal on S → `status refusal`, no retry; 429 on D → one retry after

- `test_stdout_flush`: every emitted line is flushed (pipe read in a subprocess within 50 ms).

### Package P1-4: Turn logic + headless end-to-end
Agent: worker-hard · Owns: `app/Sources/VerseTurns/**`, `app/Sources/verse-run/**`, `app/Tests/VerseTurnsTests/**`, and the
target entries for them in `app/Package.swift` · Do not touch: `app/Sources/VerseAudio/**`, `app/Sources/VerseSpeech/**`
(P1-3, read-only; report needed changes), `brain/**`, `bench/**`
Read first: spec §5.3–5.5, §5.10, §6.1; this plan's P1-2 protocol (the brain's stdin/stdout JSON lines) and the
session folder contract; `app/Sources/VerseSpeech/ListenTypes.swift` (`TranscriptEvent`, `ListenSession`);
`brain/verse_brain/runtime/protocol.py` (exact field names the brain accepts)
Decisions:
- **Priority:** English first. it/tr get only the simple cues listed; no tuning.
- **Turn ids:** `r<n>` for remote, `m<n>` for me. A remote turn starts at its first volatile event after ≥ 0.6 s
  of remote silence or after a `me` turn.
- **Partial → brain:** every volatile remote event becomes `partial{turn_id, speaker:"remote", text, cue,
  t_audio_end}`. `cue` is true when the text has a question signal:
  - en: a wh-word or auxiliary-first word order (do/does/did/can/could/would/will/is/are/have + you),
    "tell me", "walk me through";
  - it: `come|perché|quando|dove|quale|può|potrebbe`;
  - tr: `mı|mi|mu|mü` particles and `nasıl|neden|ne zaman|hangi`.
  Hesitation-only tails ("um", "uh", "ehm", "şey") never set `cue`.
- **Predictive endpoint:**
  - Emit `turn` when the remote text has not changed for `T` ms: `T` = 300 if `cue` and the text ends in a
    complete clause (ends with a content word, not a conjunction or preposition); 600 otherwise.
  - Emit immediately when a `me` event starts.
  - All thresholds are config values.
- **Addressee:** `me` if the text contains the owner name (config: `Alex`) or second-person forms
  (en `you/your`, it `tu/Lei/ti/le`, tr `sen/siz/-sın/-sınız`), or follows within 3 s of a `me` turn;
  `other` if it names another participant (config list, empty by default); otherwise `unknown`.
- **Matcher over `bank.jsonl`:**
  - Character 3–5-gram TF-IDF (lower-cased, punctuation stripped) over question + paraphrases. Use cosine
    similarity.
  - A hit is sent as `bank_hit{turn_id, bank_id, score}` when score ≥ 0.55 (config) and the margin over the second
    candidate is ≥ 0.08, sustained for 2 consecutive partials.
  - Each partial must be matched in under 20 ms for a 120-entry bank.
- **Fact chips:** names, numbers and glossary terms from `facts.jsonl` / `glossary.jsonl` that appear in the remote
  partial (case-insensitive, whole word) → `chip{turn_id, kind, text, source_ref}` events for the overlay (not sent
  to the brain).
- **`verse-run` CLI** (headless end-to-end, no UI):
  `verse-run --session DIR --lang en [--seconds N] [--file PATH]` starts `ListenSession`, starts the brain
  (`brain/.venv/bin/python -u -m verse_brain.runtime`, cwd `brain/`) as a child process, wires the events above to
  its stdin, and prints the brain's stdout lines plus `chip` and local `metric` lines as JSON on stdout.
  - It kills the brain on exit, SIGINT and error.
  - It never writes audio. The API key stays in the brain, which reads the Keychain.
Interfaces — Produces:
- `public struct TurnConfig { ownerName: String; otherNames: [String]; cueEndpointMs: Int; plainEndpointMs: Int; matchThreshold: Double; matchMargin: Double }`
- `public actor TurnEngine { init(config: TurnConfig, bank: Bank, facts: FactIndex); func ingest(_ e: TranscriptEvent) async -> [OutboundEvent] }`
- `public enum OutboundEvent: Codable { case partial(...), turn(...), bankHit(...), chip(...) }`, which encodes to the
  exact P1-2 JSON shapes.
Test cases:
- `testCueEnglish`: "Can you walk me through your last project" → cue true; "I worked on the API" → false; "Could you
  um" → false (hesitation tail).
- `testEndpointCueFast`: a cue question frozen for 300 ms → `turn` at +300 ms ±50; a non-cue statement → +600 ms.
